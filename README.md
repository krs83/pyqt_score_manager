BJJ Score Manager
Десктопное приложение для проведения турниров по BJJ/грэпплингу: подсчёт очков, ведение сеток, таймер, определение мест и формирование протоколов.

Что умеет
Подсчёт очков по ходу схватки: баллы, преимущества (adv), пенальти (pen) — отдельно для красного и синего угла.

Таймер схватки с настраиваемой длительностью (2/3/4/5 мин), паузой и звуковым сигналом по окончании.

Ведение турнирных сеток по возрастным категориям (от 4–5 до 24 лет) и количество участников (2–10 в категории).

Автоматическое определение победителя по очкам, преимуществам и пенальти.

Распределение проигравших по сетке (в т.ч. «поздние» проигравшие), жеребьёвка.

Определение призовых мест (1/2/3) и вывод на табло.

Формирование отчётов и протоколов в Excel (списки мест, медальный зачёт, протокол турнира).

Стек
Python 3, PyQt5 — интерфейс и логика приложения.

SQLAlchemy 2.0 + Alembic — модели и миграции БД (SQLite).

openpyxl — чтение/запись Excel-файлов категорий и отчётов.

PyInstaller (.spec-файлы) — сборка в исполняемый файл.

Структура
text
main.py              — точка входа
db.py, models.py     — подключение к БД и модели (Tournament, Category, Participant, Fight)
Modules/             — логика: подсчёт очков, таймер, работа с Excel, утилиты
Tables/              — обработка сеток по количеству участников (2–10)
UI/                  — интерфейс (mainWindow, экран счёта, модальные окна)
Report/              — генерация протоколов и отчётов
alembic/             — миграции БД

alembic upgrade head
